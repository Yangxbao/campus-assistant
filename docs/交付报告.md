### Java 后端（Spring Boot 3.2 + MyBatis-Plus，17 个 Controller，80+ 文件）
- 全部小程序接口 `/api/mp/**` 与管理接口 `/api/admin/**`（与契约逐一对应）
- JWT 认证 + 角色拦截（user / SUPER_ADMIN / AUDITOR / MAINTAINER）
- 微信登录：配置 WX_APPID/WX_SECRET 后走真实 jscode2session；未配置时 devMode 虚拟 openid + `devMode:true` 明示
- 内容审核流：PENDING→通过/驳回/下架/删除，写 t_audit_record 并自动发站内消息
- 失物规则匹配引擎；课程周次/单双周过滤；当前教学周计算；下一节课计算
- Excel/CSV 批量导入（返回成功/失败行明细）+ xlsx 导出 + zxing 教室二维码
- 本地文件存储（jpg/png/webp、≤8MB、EXIF 清洗、随机文件名），预留 StorageService 接口可切换 MinIO/OSS
- OCR 接口族：OcrService 接口 + HttpOcrService(可配置第三方/自建 PaddleOCR/Tesseract) + TimetableParser + 未配置时 50301
- Redis：最近浏览 zset、上传/发布限流、详情缓存，**Redis 不可用自动降级**
- Swagger 文档 <http://localhost:8080/swagger-ui.html>；操作审计切面；XSS 转义；统一异常处理

### 管理后台（Vue3 + TS + Vite + Element Plus + echarts，8 页面）
登录(角色菜单权限) / 数据看板(概览卡片+30 天趋势图+贡献排行) / 楼宇管理 / 教室管理(CRUD+批量导入导出+二维码) / 审核中心(5 类待审+图片预览+历史记录) / 举报处理 / 用户管理(封禁/详情) / 系统配置(学期节次/上传限制/OCR/存储/微信)

## 七、从零启动操作说明
```bash
# 1. 准备：JDK17+/Maven/MySQL8/Redis/Node18+pnpm
sudo service mysql start && sudo service redis-server start
# 2. 数据库（可重复执行）
bash scripts/init-db.sh
# 3. 后端（8080）
bash scripts/start.sh backend        # Swagger: http://localhost:8080/swagger-ui.html
# 4. 管理后台（5173）
bash scripts/start.sh admin          # 账号 admin / admin123
# 5. 小程序：微信开发者工具导入 miniprogram/，详情→本地设置→勾选"不校验合法域名"
```

## 八、正式发布微信小程序还需做的事
1. 注册小程序主体并配置服务器合法域名（HTTPS）
2. 将 WX_APPID/WX_SECRET 注入后端环境变量（参考 `.env.example`）
3. `pnpm build` 后用 Nginx 托管 admin/dist 并反代 /api
4. 用后台批量导入录入真实教学楼/教室数据，删除演示数据
5. 申请订阅消息模板并配置模板 ID
6. 小程序提审时声明：用户生成内容(UGC)+社区审核机制
